## 3. 详细介绍

**路由网关** 是一款运行在飞牛 fnOS 上的原生网关工具，把「端口转发、反向代理、证书管理」三件事放进同一个管理界面，免去在路由器后台、证书控制台之间反复切换。

- **端口转发**：自动发现局域网路由器（UPnP IGD），可视化增删端口映射；路由器重启或映射丢失后自动补发，无需手动干预。
- **反向代理**：采用「入口（监听端口/协议/TLS）+ 路由（域名/路径→后端）」双层模型，支持 HTTP、HTTPS、TCP 三种协议；基于域名（含泛域名）、路径进行路由；HTTPS 支持 SNI 动态证书、HTTP→HTTPS 跳转、HSTS、自定义响应头、访问日志。
- **证书管理**：统一管理所有证书来源——飞牛系统证书**只读导入**（不回写系统证书库）、手动上传 PEM、一键自签内网证书、以及通过 ACME（Let's Encrypt / 自定义 Directory）申请**泛域名证书**并**自动续期**。反向代理直接按证书选择即可生效，证书续期后**零重启**自动加载新证书。

所有管理操作都在飞牛统一网关内完成，不额外占用管理端口；管理接口做了同源校验与写操作 CSRF 防护。

## 4. 功能清单（核对用）

**路由转发**
- [x] UPnP IGD1/IGD2 自动发现网关
- [x] 端口映射增 / 删 / 重新启用
- [x] 路由器重启后自动补发（可暂停）
- [x] 网关指纹保护，防止误删其他设备映射
- [x] 枚举外部已有映射，可选择性清理

**反向代理**
- [x] 入口（Listener）：端口 / 协议(http,https,tcp) / 绑定地址 / TLS / HSTS / HTTP 跳转
- [x] 路由（Route）：精确域名、泛域名 `*.example.com`、空域名任意匹配、路径前缀 / 精确匹配、最长路径优先
- [x] 后端代理：保留 `http/https` scheme、路径前缀剥离、`X-Forwarded-*`、`X-Real-IP`、请求头改写、后端 TLS 校验开关、WebSocket、超时
- [x] TCP 代理：TLS ClientHello SNI 分流、非 TLS 兜底
- [x] 访问日志、健康检查、增量应用（纯路由变更不重建监听、不中断连接）
- [x] 证书按 `cert_id` 引用，续期零重启生效

**证书管理**
- [x] 证书列表（有效期、剩余天数、密钥类型、是否泛域名、是否被引用、是否默认）
- [x] 手动上传 PEM（私钥 + 证书链，自动解析 SAN / 有效期 / 通配符）
- [x] 导出证书包：证书链 + 私钥 + 导入说明打包为 ZIP，用于导入飞牛系统证书（POST + CSRF + 二次确认）
- [x] 飞牛系统证书只读导入（root helper 复制为应用私有快照）
- [x] 一键自签内网证书（ECDSA/RSA）
- [x] ACME 申请：Let's Encrypt / Staging / 自定义 Directory（含 EAB）
- [x] DNS-01 验证：阿里云 DNS、腾讯云 DNSPod、Cloudflare、手动 TXT
- [x] 支持泛域名证书、自动续期（到期前 30 天检查、失败退避、原子切换）
- [x] 引用保护：被反向代理引用的证书不可删除

**安全**
- [x] 管理面仅经统一网关 Unix Socket，不监听管理 TCP 端口
- [x] 同源校验 + 写操作 CSRF Token
- [x] 私钥与 DNS 凭据隔离在 `secrets/`（0700/0600），不进配置文件、不进日志
- [x] 私钥仅在用户显式「导出证书包」时随 ZIP 下发：POST + CSRF Token + 二次确认，`no-store`，JSON 响应中永不含私钥

## 5. 权限说明（重要，审核常问）

| 权限 / 行为 | 原因 | 影响范围 |
|---|---|---|
| 以 root 启动，随后降权 | 仅为了拿到 `cap_net_bind_service`，以便绑定 80/443 等 1024 以下端口 | 启动后进程立即降权为应用用户 `fngate`，并非以 root 常驻 |
| 读取飞牛系统证书 | 把系统证书**复制**为应用私有快照，供反向代理选用 | **只读**，不修改、不回写系统证书库 |
| 写入自身数据目录 | 保存配置、证书、日志、ACME 账户 | 仅应用自身目录，不触碰系统其他文件 |
| 导出证书包（用户主动触发） | 用户需要把证书导入飞牛系统或其它设备时，提供证书链与私钥的 ZIP | 由用户点击「导出」并二次确认后发生，服务端不保留副本 |

应用不会：访问路由器之外的网络、回写飞牛系统证书、上传任何凭据到第三方（ACME 仅与用户所选 CA 通信）。

## 6. 安装与使用

1. 飞牛「应用中心 → 设置 → 手动安装」，上传 `fngate-1.0.0.fpk`。
2. 安装完成后，从桌面图标打开（走飞牛统一网关，不占用管理端口）。
3. 端口转发：确保路由器已开启 UPnP；进入「端口转发」自动发现网关后添加映射。
4. 反向代理：在「反向代理」新建入口（如 HTTPS 443），再为每个域名/路径添加路由并选择证书。
5. 证书：在「证书管理」上传 / 导入飞牛证书 / 自签 / 用 ACME 申请泛域名证书；申请泛域名需对应 DNS 服务商的 API 凭据（或使用手动 TXT 验证）。

## 7. 常见问题（FAQ）

**Q：绑定 80/443 失败？**
A：应用以 root 启动并授予 `cap_net_bind_service` 后降权运行；若文件系统不支持 xattr（setcap 无法落盘），会自动退回 root 运行以保证功能可用。可在「设置」查看运行身份。

**Q：泛域名证书怎么申请？**
A：需要在「域名解析」页的 DNS 服务商中添加对应凭据（阿里云 / 腾讯云 DNSPod / Cloudflare）的 API 凭据，或选择「手动 TXT」在 DNS 后台手动添加 `_acme-challenge` 记录完成验证。

**Q：证书续期需要重启吗？**
A：不需要。证书续期后动态证书解析会在下次 TLS 握手自动使用新证书，反向代理零重启生效。

**Q：飞牛系统证书会被动过吗？**
A：不会。系统证书仅被复制为应用私有快照，反向代理选用即可，应用绝不回写系统证书库。

**Q：想让飞牛自己也用申请的证书怎么办？**
A：在证书列表点「导出」，得到含 `fullchain.pem` 与 `privkey.pem` 的 ZIP，到飞牛「系统设置 → 网络 → 证书」手动导入。
导出走 POST + CSRF 且需二次确认，私钥不经过任何 JSON 接口。应用不自动写飞牛证书库——那属于系统内部实现，写错会让飞牛桌面 HTTPS 打不开。

**Q：卸载会删数据吗？**
A：卸载向导会提示是否保留数据目录（含证书私钥、ACME 账户密钥、DNS 凭据）。应用不会删除路由器映射，也不会修改飞牛系统证书。
